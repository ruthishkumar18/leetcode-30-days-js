# Day 28 — 2694. Event Emitter

## Problem
Design an EventEmitter class that allows:
- Subscribing to events
- Emitting events with arguments
- Unsubscribing from events

## Requirements
- Multiple listeners per event
- Call listeners in subscription order
- emit returns array of callback results
- unsubscribe removes the callback

## Actions
- EventEmitter
- subscribe
- emit
- unsubscribe
