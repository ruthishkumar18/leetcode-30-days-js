# Day 22 — 2619. Array Prototype Last

## Problem
Enhance all arrays so that calling `array.last()` returns the last element.

- If the array is empty, return `-1`.
- You may assume the array is the result of `JSON.parse`.

## Examples
- [null, {}, 3].last() → 3
- [].last() → -1

## Constraints
- 0 <= arr.length <= 1000
