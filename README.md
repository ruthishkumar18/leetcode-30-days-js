## 🧠 Concepts Practiced

- **Functions and closures:** returning functions, counters, memoization, and function composition.
- **Array methods:** transformation, filtering, reduction, chunking, sorting, grouping, and joining data.
- **Asynchronous JavaScript:** promises, time limits, cancellation, parallel execution, and timers.
- **Objects and prototypes:** checking objects, adding prototype methods, compacting objects, and event emitters.
- **Reusable patterns:** debouncing, caching, wrappers, and method chaining.

## 🗂️ Repository Structure

Each day follows a simple, consistent structure:

```text
day-01/
├── problem.md
└── solution.js
```

- `problem.md` contains the problem statement and examples.
- `solution.js` contains the JavaScript solution.

The same structure is used across the daily folders to make each solution easy to explore.
